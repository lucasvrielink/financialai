# Personal Finance AI — Project Context

## What this project is
A personal finance bot that receives messages in natural Brazilian Portuguese via Telegram,
interprets them using Gemini AI, saves structured transactions to Firebase Firestore,
and exposes a web dashboard to view and manage transactions.

## Examples of messages the bot understands
- "45 academia" → despesa R$45 categoria saúde
- "salario 5000" → receita R$5000 categoria renda
- "paguei janta 60" → despesa R$60 categoria alimentação
- "3x 150 sapato" → despesa parcelada R$150x3 categoria vestuário

## Stack
- **Backend:** FastAPI (Python) — deployed on Render
- **Frontend:** Next.js (TypeScript) — deployed on Render as Static Site
- **Database:** Firebase Firestore
- **Auth:** Firebase Auth — email and password only (no social login)
- **Telegram:** python-telegram-bot
- **NLP:** Gemini API (Google AI Studio) — `google-generativeai` package
- **ML (future):** scikit-learn, pandas, LangChain

## Firestore collections
- `transactions` — financial transactions saved by the bot
- `users` — user profiles (managed by Firebase Auth)

## How agents work
This project uses Spec-Driven Development. Before implementing any feature:
1. Run `requirements-agent` to define what the feature does
2. Run `design-agent` to define how it's built
3. Run `task-creator-agent` to break it into tasks
4. Run `implementation-agent` to write the code

Specs live in `.claudedoc/<feature-name>/`. Always read them before touching code.

## Render deploy
- Backend: Web Service → root `/backend`, start command `uvicorn main:app --host 0.0.0.0 --port $PORT`
- Frontend: Static Site → root `/frontend`, build command `npm run build`, publish dir `out`

## Key conventions
- Backend: async/await everywhere, Pydantic models for all data, python-dotenv for env vars
- Frontend: Next.js App Router, Server Components by default, `use client` only when needed
- Never hardcode credentials
- Always validate Telegram webhook secret token before processing messages
- Gemini prompt must handle informal Brazilian Portuguese
